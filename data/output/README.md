# Pipeline Output

Generated by `rebuild_db.py`, `audit.py`, and `export_public.py`. **None of these files are committed to git** (`.gitignore` excludes `*.db`, `*.csv`, `*.log`).

## Database files

| File | Type | Size | Description |
|---|---|---|---|
| `ufo_unified.db` | **PRIVATE** | ~1.8 GB | Full database with all raw narrative text, audit data, sentiment tables. This is the canonical working database — all pipeline tools read/write here. **Never distribute.** |
| `ufo_public.db` | **PUBLIC** | ~553 MB | Clean export with raw text stripped. Safe to distribute and deploy to production. Generated by `export_public.py`. |

### How to generate

```bash
python rebuild_db.py          # builds ufo_unified.db (16 steps, ~30 min)
python export_public.py       # builds ufo_public.db from ufo_unified.db
```

## Audit cache files

These are the cached results from LLM-powered data quality audits. They are **replayed automatically** on future rebuilds (no API key needed).

| File | Description |
|---|---|
| `audit_tier_b_fixes.csv` | 49K LLM-derived location normalizations. Columns: `sighting_id, raw_location, original_city/state/country, new_city/state/country, confidence, notes, timestamp`. Replayed by `audit.py --replay`. |
| `audit_tier_b_results.csv` | Full audit results for all 214K audited rows (fixes + no-change + errors). Backup only — not used by the pipeline. |
| `audit_tier_b.log` | Timestamped run log from the live audit. Backup only. |

### Re-running a live audit (requires API key)

```bash
export OPENROUTER_API_KEY="sk-or-v1-..."
python run_audit.py --workers 15      # ~$3-5 via Gemini Flash
```

This produces fresh `audit_tier_b_fixes.csv` and `audit_tier_b_results.csv`.

## For the dev team

**To update the website**, you need `ufo_public.db`. Run:

```bash
python export_public.py
# Then hand data/output/ufo_public.db to the dev team
# They run: python migrate_sqlite_to_pg.py --source ufo_public.db
```

The private DB (`ufo_unified.db`) never leaves this machine.
