# Data Directory Layout

This directory contains all data artifacts for the UFOSINT unified sighting pipeline. **No data files are committed to git** — only the folder scaffolding and README files that describe what goes where.

## Directory structure

```
data/
├── raw/                    Source datasets (obtained externally)
│   ├── README.md           Per-source acquisition instructions
│   └── reddit/             Reddit r/UFOs extraction pipeline artifacts
│       ├── raw/            Scraped post JSON files (Pass 1)
│       ├── extracted/      LLM-extracted JSON files (Pass 2)
│       ├── reddit_sightings_extracted.csv   Import-ready CSV (Pass 3 input)
│       ├── work_queue.json                  Scrape job queue
│       ├── scrape_log.json                  Scrape progress tracker
│       └── extract_log.json                 Extraction progress tracker
│
├── output/                 Pipeline outputs (generated by rebuild_db.py)
│   ├── README.md           Output file descriptions
│   ├── ufo_unified.db      PRIVATE — full database with raw text (~1.8 GB)
│   ├── ufo_public.db       PUBLIC — derived fields only, safe to ship (~553 MB)
│   ├── audit_tier_b_fixes.csv    Cached LLM location fixes (replayed on rebuild)
│   ├── audit_tier_b_results.csv  Full audit results backup
│   └── audit_tier_b.log         Audit run log
│
├── cache/                  LLM inference cache (for replay without re-calling APIs)
│   └── README.md
│
└── models/                 Model artifacts and configs
    └── README.md
```

## Key principle: deterministic replay

The pipeline is designed so that **expensive operations** (LLM inference, GPU emotion classification) produce cached artifacts that can be replayed on future rebuilds without re-running the inference.

| Expensive step | Cache artifact | Replay mechanism |
|---|---|---|
| Tier B location normalization | `output/audit_tier_b_fixes.csv` | `audit.py --replay` |
| Reddit LLM extraction | `raw/reddit/extracted/*.json` | `extract_reddit.py --merge` |
| Emotion classification | Stored directly in DB columns | `emotions.py` skips non-NULL rows |

A fresh `python rebuild_db.py` replays all cached results automatically. Only run the live LLM/GPU tools when you have new data to process.
